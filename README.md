# DOLFIN PROJECTS Website

Multi-page static site (HTML5, CSS3, vanilla JavaScript). No frameworks, no build step needed to run it.
Domain configured: `https://www.dolfinprojects.com/`

## 1. Run locally
```
cd site
python3 -m http.server 8000      # then open http://localhost:8000
```
(Or open any `.html` file directly; use a local server for best results.)

## 2. File structure
```
site/
  index.html … contact.html      25 pages (21 required + product.html detail, privacy, terms, 404)
  css/style.css                  design system
  js/config.js                   ★ company phone, WhatsApp, email, address, form endpoint, logo
  js/main.js                     nav, contact links, reveal, project filters
  js/products.js                 catalogue search/filter/sort/detail rendering
  js/forms.js                    enquiry form validation + delivery handling
  data/products.js               ★ brands, categories, products (data only)
  assets/images/{products,brands}/  put real images here
  sitemap.xml, robots.txt
tools/
  build.js + content.js          page generator (shared header/footer/SEO + service content)
  check.js, browser_test.py      link checker and browser tests
```

## 3. Before going live — required items (placeholders)
Still outstanding (not supplied, so nothing was invented):
1. **Contact details** — phone, WhatsApp, email and address are set in `js/config.js`. Business hours are blank (hidden on the site) until you add `hours`.
2. **Logo** — official logo is in `assets/images/logo.png` (set via `logoPath`).
3. **Photos & logos** — every slot currently shows an original illustration (`assets/images/illustrations/`, generated by `tools/make_illustrations.py`). Brand cards show the brand name as text. To use real images: save authorised brand logos as `assets/images/brands/<brand-id>.png` (ids: fosroc, chryso, cac, normet, kerakoll, myk-laticrete, myk-arment, asian-paints), and photos as described next, then run `node tools/build.js`. Details: every image slot shows a labelled placeholder until you add a photo. Save photos (jpg/webp/png) into `assets/images/photos/` using the names in `assets/images/photos/FILENAMES.txt`; product photos go in `assets/images/products/<product-id>.jpg`. Then run `node tools/build.js` (it regenerates `js/photos-manifest.js`) and re-upload. Only use photos you own or are authorised to publish (including brand-supplied product images).
4. **Products** — the catalogue lists ~135 product names/ranges taken from the brands' official websites (Fosroc, MYK Laticrete, Kerakoll, Normet, Chryso, CAC), each with a link to the manufacturer page (`source`) and a “Manufacturer range” badge. Remove anything DOLFIN PROJECTS does not supply, and add datasheet/image paths for what you do. MYK Arment and Asian Paints have placeholder entries only (no source consulted). Brand logos/images and manufacturer datasheets are not copied — use authorised files from the brands.
5. **Projects** — `projects.html` entries are labelled demo content.
6. **Brands** — confirm authorised/trading status of each brand, and confirm Asian Paints, CAC and MYK Arment categories. Add Mapei, Sika, etc. only if confirmed.
7. **Legal** — Privacy Policy and Terms are draft templates; have them reviewed.
8. **About page** — add verified history, certifications and clients only when confirmed.

After editing `config.js`, rebuild so structured data picks up phone/email: `node tools/build.js`.

## 4. Adding products
Edit `data/products.js`. Add a full record to the `P` array, or use the helper `add(brandId, categoryId, type, description, applications, features)`.
```js
{ id:"fosroc-example", name:"Product name", brand:"fosroc", category:"waterproofing",
  type:"Liquid-Applied Membrane", description:"…", applications:["Waterproofing"],
  features:["…"], specs:{"Density":"value from datasheet"}, packaging:"", coverage:"",
  datasheet:"assets/docs/example-tds.pdf", sds:"", image:"assets/images/products/example.jpg", demo:false }
```
Leave `specs`, `packaging`, `coverage` empty if unverified — the site then shows “Specifications available on request” / “Refer to Technical Datasheet”. Prices are never shown (“Contact for Price”).
Category ids: `admixtures`, `repair-grouts`, `waterproofing`, `tile-adhesives`, `speciality`. Brand ids are in `DOLFIN_BRANDS`.
Hundreds of products need no template changes — cards, filters, counts and detail pages are generated from the data.

## 5. Connect enquiry forms to a real backend
A static page cannot send email. Until `formEndpoint` is set, forms validate the entry and then offer **WhatsApp / email hand-off**; they never claim the enquiry was delivered.
Options:
- **Form service (easiest):** create a form at Formspree, Getform, Basin, etc. and paste its URL into `formEndpoint` in `js/config.js`. The form POSTs JSON and shows success only on an OK response.
- **Own backend:** expose an HTTPS endpoint (PHP/Node/serverless) accepting JSON with: `enquiryType, name, company, phone, email, city, projectType, requirement, quantity, message`, returning HTTP 200 on success. Add spam protection (CAPTCHA/rate limit) and CORS for your domain.
A hidden honeypot field blocks basic bots.

## 6. Editing page content / rebuilding
Header, footer, home, category, brand and utility pages are generated by `tools/build.js`; the seven service pages' text is in `tools/content.js`. Edit, then run `node tools/build.js` (Node 16+). This regenerates HTML, `sitemap.xml` and `robots.txt`. Don't hand-edit generated HTML if you plan to rebuild.

## 7. Deploy
Upload the contents of `site/` to the web root of the hosting for www.dolfinprojects.com (cPanel File Manager/FTP, Netlify, Cloudflare Pages, GitHub Pages or any static host). Point the domain's DNS to the host, enable HTTPS, and submit `https://www.dolfinprojects.com/sitemap.xml` in Google Search Console. Optionally configure the host to serve `404.html`.
